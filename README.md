## 📦 Paquetes Instalados

Haz clic en cualquier comando para seleccionarlo y copiarlo:

| Paquete | Comando | Descripción |
|---------|---------|-------------|
| neofetch | `pkg install neofetch -y` | Muestra información del sistema con diseño ASCII |
| socat | `pkg install socat -y` | Utilidad de red para transferir datos entre dos canales |
| screen | `pkg install screen -y` | Multiplexor de terminal para sesiones persistentes |
| vim | `pkg install vim -y` | Editor de texto potente y altamente configurable |
| tsu | `pkg install tsu -y` | Ejecuta comandos como root en Termux |
| php | `pkg install php -y` | Lenguaje de programación para desarrollo web |
| git | `pkg install git -y` | Sistema de control de versiones distribuido |
| figlet | `pkg install figlet -y` | Genera banners de texto en ASCII art |
| toilet | `pkg install toilet -y` | Crea texto decorativo en ASCII con más estilos |
| unzip | `pkg install unzip -y` | Extrae archivos comprimidos en formato ZIP |
| cmake | `pkg install cmake -y` | Sistema de construcción multiplataforma |
| nmap | `pkg install nmap -y` | Escáner de red y auditoría de seguridad |
| w3m | `pkg install w3m -y` | Navegador web en modo texto |
| aria2 | `pkg install aria2 -y` | Descargador de archivos ligero y multiprotocolo |
| dex2jar | `pkg install dex2jar -y` | Convierte archivos Android DEX a JAR |
| nano | `pkg install nano -y` | Editor de texto simple y fácil de usar |
| requests | `pip3 install requests` | Librería Python para peticiones HTTP |
| wget | `pkg install wget -y` | Descargador de archivos desde la web |
| htop | `pkg install htop -y` | Monitor de procesos interactivo y visual |
| colorama | `pip3 install colorama` | Colores en terminal para Python |
| glow | `pkg install glow -y` | Renderizador de Markdown en terminal |
| python2 | `pkg install python2 -y` | Versión 2 del lenguaje Python (legacy) |
| nodejs | `pkg install nodejs -y` | Entorno de ejecución para JavaScript |
| zip | `pkg install zip -y` | Comprime archivos en formato ZIP |
| ruby | `pkg install ruby -y` | Lenguaje de programación dinámico y elegante |
| curl | `pkg install curl -y` | Transfiere datos con URLs mediante diversos protocolos |
| perl | `pkg install perl -y` | Lenguaje de scripting para procesamiento de texto |
| screenfetch | `pkg install screenfetch -y` | Muestra información del sistema (alternativa a neofetch) |
| sl | `pkg install sl -y` | Muestra una locomotora de vapor animada (easteregg) |
| tmux | `pkg install tmux -y` | Multiplexor de terminal moderno y configurable |
| make | `pkg install make -y` | Automatiza la compilación de programas |
| openssh | `pkg install openssh -y` | Cliente y servidor SSH para conexiones remotas |
| pv | `pkg install pv -y` | Muestra progreso de datos en tuberías |
| openssl | `pkg install openssl -y` | Herramientas criptográficas y SSL/TLS |
| python | `pkg install python -y` | Lenguaje de programación Python 3 |
| hollywood | `pkg install hollywood -y` | Simula una consola de hacker de película |
| clang | `pkg install clang -y` | Compilador de C/C++ de LLVM |
| cowsay | `pkg install cowsay -y` | Muestra una vaca que dice mensajes personalizados |
| tcpdump | `pkg install tcpdump -y` | Analizador de tráfico de red en tiempo real |

---

### 🚀 Instalación rápida (todos los paquetes)

```bash
pkg install neofetch socat screen vim tsu php git figlet toilet unzip cmake nmap w3m aria2 dex2jar nano wget htop glow python2 nodejs zip ruby curl perl screenfetch sl tmux make openssh pv openssl python hollywood clang cowsay tcpdump -y && pip3 install requests colorama
